# Company — the shared brain

Read these files in this order at the start of every run. They are the standing context
for all content skills and the ads engine. Nothing is generated without them.

## Reading order

1. `brand.md` — voice, tone, what we never say. Non-negotiable constraints.
2. `product.md` — what the product is, what it does, current focus.
3. `icp.md` — who the content is for. Write to this person.
4. `offers.md` — what CTAs are live right now. Every post ends with one of these.
5. `memory/content-performance.md` — lessons from past posts. Read last so recent
   rules override older ones.

## How to update

- Edit any file directly. Changes take effect on the next run — no reinstall needed.
- When something ships or a promotion changes, update `product.md` and `offers.md`.
- Do NOT put competitor information in this folder. Keep the focus on our own voice
  and product — the AI performs better without competitor noise in context.
- `memory/content-performance.md` is appended automatically by the nightly self-study.
  Do not hand-edit it; add manual notes as a dated entry if needed.
